## Core Patterns

- **Calibrated Technical Tone**: Calibrated Tone Filter: purge dogmatic claims ('obviously', 'clearly') and weak hedges ('might perhaps maybe'); assert verifiable facts.
- **Practical Application**: Professional architectural reviews and security disclosures.
- **Verification Gate**: Enforces clean syntax, zero filler, and deterministic causality.
